วิธีใช้: กรอกชื่ออุปกรณ์ หน่วย และราคา แล้วกด “บันทึกรายการอุปกรณ์” รายการที่บันทึกแล้วจะปรากฏด้านล่างและในช่องเลือกอุปกรณ์ของหน้าใบเสนอราคา

วิธีย้ายข้อมูลไปอีกเครื่อง

  1. เครื่องเดิม: กดดาวน์โหลดไฟล์สำรอง
  2. ส่งไฟล์ JSON ไปยังโทรศัพท์/iPad/คอมพิวเตอร์เครื่องใหม่
  3. เปิดเว็บแอปบนเครื่องใหม่ แล้วกดนำเข้าไฟล์สำรอง
  4. เลือกไฟล์ JSON ที่ได้รับ
